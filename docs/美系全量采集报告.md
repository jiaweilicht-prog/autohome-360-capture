## 四、效率优化（本轮落地）
- 新增 `--fast-scene` 开关：**跳过逐站位渲染比对，直接采用首个匹配机位**。
- 单台耗时由 ~160s 降至 **~40-50s**（省约 70%）。
- 车头方向判定（0° 快速通道 / 对称+亮带交叉校验）**保留**，确保不拍错方向。
- 风险兜底：低对称度图自动写入 `output/qc_flags.csv`，跑完人工复核。

## 五、质检
- 出图体检可疑：**2 张**（对称度低于阈值）——科帕奇 R1（0.72）、开拓者(海外) R1（0.87）。
- **人工目检结论：2 张均合格**，系真实内饰左右不对称（方向盘偏左、中控偏向主驾）导致阈值误判，非构图偏轴。
- 锚点低置信待复核：1 条（见 `output/anchor_review.csv`）。

## 六、命名规则（DDGS 8 段）
`IMG_{BRAND}_{MODEL}_{GEN}_{VIEW}_{SUBID}_{SOURCE}_{SEQ}.png`

- **BRAND**：BUICK / CHEVY / FORD / CADI / LINCOLN / JEEP / CHRY / DODGE / TESLA / GMC
- **MODEL**：可识别拉丁车型码（如 EQUINOX / EXPLORER / ESCALADE / MODEL3 / CHALLENGER）；同车型多版本带区分后缀（`-IMP` 进口 / `-CN` 国产 / `-PHEV` / `-XL`），确保每 pano 唯一、不碰撞。
- **GEN / SUBID**：美系无对应体系码，统一 `NA`（沿用「没有就 NA」规则）。
- **VIEW**：IPDRV（主驾位前望）/ IPFRONT（前舱正视）
- **SOURCE**：AUTO360　**SEQ**：01
