## 四、命名规则（DDGS 8 段）
`IMG_{BRAND}_{MODEL}_{GEN}_{VIEW}_{SUBID}_{SOURCE}_{SEQ}.png`

- **BRAND**：MER / BMW / AUDI / VOLVO / POR / LR / FER / LAM / BEN / RR / PEU / DS / POLE / INEOS / ASTON / BUGA / KONI / LEVC / MCLAREN / MORGAN / LOTUS
- **MODEL**：可识别拉丁车型码（S-CLASS / X5 / 911 / URUS / CONTINENTAL / CULLINAN / 3008 / DBX / DIVO / ARTURA …）
- **GEN / SUBID**：欧系绝大多数无年代/代际字段，统一 `NA`（沿用「没有就 NA」规则）。
  - **例外（宝马）**：宝马此前已有专项批次，沿用其**真实代际码**（X3=G01 / X5=G38 / 7系=G70 / Z4=G29 / iX3=G08，SUBID=0204/0101）；宝马 iX / i7 / i8 / XM / M8 无既有码，仍用 `NA`（待补）。
- **VIEW**：主驾位前望→`IPDRV`；前舱正视→`IPFRONT`。**SOURCE**=`AUTO360`，**SEQ**=`01`。

## 五、质检
- **出图体检可疑：1 张** —— 兰博基尼 Aventador F1（对称度 0.7413 < 0.75）。**人工目检合格**：兰博中控台天然偏向主驾侧（右侧品牌标 + 出风口），属真实内饰不对称，非构图偏轴；且该车经 0° 快速通道确认车头方向无误。
- **锚点低置信待复核：2 条** —— 保时捷 918 Spyder、兰博基尼 Aventador（超跑内饰左右差异小 → 匹配间距偏小）。两者均已用 0° 快速通道/模板确认为 h=0°，方向无误。
- **视口一致性**：全部 532 张欧系及相关出图统一 2880×1428（修复了 10 张某次运行残留的 2884×1414 异常件）。
