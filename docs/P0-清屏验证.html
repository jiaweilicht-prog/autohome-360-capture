P0 补充：清屏按钮验证

2026-09-03，针对用户提示的「右上角清屏按钮」做程序化验证。

结论

  • 清屏按钮可用：通过 document.querySelector('.hide-btn').dispatchEvent(click) 即可触发，无需做视觉坐标定位。
  • 清屏效果确切：左侧机位栏、顶部「反馈/分享/清屏」、底部配色条、右侧询价按钮、热点标签全部隐藏，画面只剩全景本身。
  • 水印去不掉：「汽车之家」水印烘焙在全景 tile 里，elementFromPoint 返回 krpano 容器而非 DOM 元素；清屏按钮对它无效。
  • 不影响机位控制：清屏后仍可通过 krpano.call('loadscene(...)') 切换 scene，适合批量截图流程。

触发代码

// 页面加载并停转后，直接派发点击事件
await page.evaluate(() => {
  const el = document.querySelector('.hide-btn');
  if (el) {
    el.dispatchEvent(new MouseEvent('click', { bubbles: true, cancelable: true, view: window }));
  }
});
await page.waitForTimeout(800);

对后处理的影响

  • 截图前加一步清屏，可得到「无 UI 控件」的干净构图，比后期擦除按钮/热点更合规、更稳定。
  • 水印仍只能通过合规裁剪避开（若目标区域不覆盖水印区）、官方授权、官方素材源或自行拍摄解决。
  • 配置 task.autohome360.yaml 已在 capture.pre_actions 中加入 dispatch_click .hide-btn。

水印位置参考

在 1440×900 的截图中，水印大致位于右侧偏中区域（x≈1000–1300，y≈140–280）。批量后处理时，若目标机位需要完整右中区域，必须接受水印或改用合规来源。
