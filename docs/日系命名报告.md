## 4. 关于"各存一份、命名后不同名"

- JP 原始抓图主要落在 `output/images_by_view/{主驾位前望,前舱正视}/`，使用原始中文命名（如 `丰田_铂智4X_默认_主驾正视前排IP_01.png`），未做双目录复制。
- 命名后保留单副本于原目录（各存一份 = 不删除、不合并），文件名转为 DDGS 规范 `IMG_..._01.png`；F1/R1 因视角后缀（IPDRV/IPFRONT）天然不同名。
- 轩逸此前有 `IMG_NA_SYLPHY`（早期 NA 口径）副本，本次一并转为 `IMG_NIS_SYLPHY`；两处副本内容 md5 一致，无丢图。
